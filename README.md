# Maven World database
## Programmas apraksts
Programma kas atlasa datus no DB World un parāda tos cauri GUI.
Ar datiem var veikt dažādas darbības un izsaukt skatus.
Programma arī pārbauda vai tiek ievadīti korekti dati datubāzē un ja nē, tad izvada paziņojumu par attiecīgo kļūdu.
